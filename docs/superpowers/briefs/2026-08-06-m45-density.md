## The work

Make the binding surface readable at scale without deleting a fact from it. That is the whole
problem, and it is genuinely harder than the table W141 fixed, because there is nothing there that
says nothing.

Options worth measuring rather than assuming — and **measure before choosing**, because the last two
attempts at this were both wrong about the cause:

- Constraining which column is allowed to wrap, so one long value does not set the row for eight
  short ones.
- Truncation with the full value reachable, if and only if the truncated form still carries enough
  to identify the row. A truncated call-site path that a reader cannot match to their editor is a
  column that has stopped being a fact.
- A second line by design rather than by accident, if the pairing is genuinely two facts about one
  thing.

**`break-words` has to survive whatever you pick.** A customer-supplied path with no break
opportunity must not overflow the column, and B109 records that constraint because it eliminated one
of the candidates.

**Closes when** the binding surface's row height is measured before and after at `--scale 10000`,
rows above the fold are reported at 900px and 800px, and no column has stopped being able to
identify its row. If the honest answer is that no change is worth its cost, say that with the
numbers — B109 already contains one such finding, and it was the more useful half of that item.

## Constraints

- The 5.05:1 text floor against rendered pixels and the 11px size floor both hold. `DESIGN.md`'s
  ramp does not exempt a value from the floor.
- Two ink levels plus one accent; two font weights. The conformance report says which routes clear
  these — do not regress one.
- Twenty-four protected sentences: restyling allowed; deleting, shortening, collapsing behind a
  disclosure or moving into a tooltip is not.
- No composite score, health figure, traffic light, green dot, liveness pulse or count-up.
- No motion. `lib/motion.ts` carries a registry that a Python guard binds to the tree in both
  directions, so an unlisted importer fails the build. Do not add a caller.
- Logic with a wrong answer lives in Python; rendering-side classification is tested with `vitest`.
