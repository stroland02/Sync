Workflows

The Workflows API allows you to programmatically create, manage, and execute automation sequences within the Sync platform. Use these endpoints to integrate internal logic with external systems.

List all workflows

Returns a paginated list of all active workflows associated with your current environment.

GET https://api.sync.dev/v2/workflows

Query Parameters

Parameter Type Description
limit integer Maximum number of records to return.
Default: 20, Max: 100
status string Filter by workflow status. Valid options are active, paused, or failed.

Create a workflow

Creates a new automation workflow. You must provide a valid JSON configuration detailing the trigger and steps.

POST https://api.sync.dev/v2/workflows

Body Parameters

Parameter Type Description
name Required
string The display name of the workflow. Max 128 characters.
trigger_type Required
string Defines how the workflow initiates. Must be webhook, schedule, or event.
