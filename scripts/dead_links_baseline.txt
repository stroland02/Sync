# Public symbols nothing in `src/` reaches, accepted as of 2026-07-28.

# This is a list and never a threshold. A count absorbs both a repair and a new defect in
# silence; a named entry has to be deleted by whoever wires the symbol up, in the commit that
# wires it, because `lint_dead_links.py` fails on an entry that no longer describes anything.
# The file only shrinks. Adding a line is a decision, not a formality: it says a component is
# finished, tested, and reachable from nothing, and that somebody accepted that on purpose.

# found, and it is silent on `GraphStore.set_merge_outcome` and `sync.route.matrix.route()`,
# which were on the same list until they were wired.
