# Public symbols nothing in `src/` reaches, accepted as of 2026-07-28.

# This is a list and never a threshold. A count absorbs both a repair and a new defect in
# silence; a named entry has to be deleted by whoever wires the symbol up, in the commit that
# wires it, because `lint_dead_links.py` fails on an entry that no longer describes anything.
# The file only shrinks. Adding a line is a decision, not a formality: it says a component is
# finished, tested, and reachable from nothing, and that somebody accepted that on purpose.
#
# Every entry below was already known and recorded in a spec before this lint existed. That is
# the evidence the lint works: it independently rediscovers what four separate manual sweeps
# found, and it is silent on `GraphStore.set_merge_outcome` and `sync.route.matrix.route()`,
# which were on the same list until they were wired.
#
# Format: <path from the repository root>:<qualname>

# The publishing half of the change feed: built, and run by nothing. Rendering and signing a
# feed is a publish job, which `2026-07-26-sync-public-change-feed.md` places outside the
# architecture on purpose -- the keypair and the job are operational. `public_key_bytes` is how
# the committed development key in `sync.core.keys` was derived, once, in a process that kept
# no private half. These leave when something in this tree publishes.

# The MCP server adapter, unreachable for a reason the registry cannot currently express.
# `_BUILDERS` maps one vendor id to one builder, which suits a vendor that publishes one API.
# MCP is a protocol, not a vendor: every server watched is a separate catalogue, so an entry
# keyed `mcp` would have to name one server and would be the vendor knowledge that module exists
# to keep out. Wiring it needs a decision about how a deployment declares which servers it
# watches -- the configured `generated-vendors.yaml` path is the closest existing shape. It
# leaves when that decision is made.
src/sync/signals/mcp_server/adapter.py:McpServerAdapter
src/sync/signals/feed/publisher.py:render_feed
src/sync/signals/feed/publisher.py:sign_feed
src/sync/signals/feed/publisher.py:public_key_bytes
